# English proofreading: `src/Texts/*.sql` (en_US)

> Applied on 10-25: all 34 rows (including the 3 optional ones) are now in `src/Texts/*.sql`. Skipped rows: none.

Scope: all 237 `en_US` strings in the 13 text files (235 in `LocalizedText`, plus the 2 Cecil-link lines that live in `BaseGameText`). `TsoDTE_Text_Religion.sql` (7 strings, War God Faith) arrived with the branch merge and is included. zh_Hans_CN has the same 237 tags, so no tag is missing in either language. Nothing under `src/` was edited; this table is for the coordinator to apply.

How to apply: each row gives the full replacement string. Apostrophes are shown as single characters; double them (`''`) inside SQL. Pedia rows keep the typographic apostrophe the file already uses.

Checked against: the house rules (effect texts have no second person and no introductory flavour), `docs/ids.md` §6 terms, and the official en_US text in the game files (Base and DLC `Text/en_US`) for Civ6 phrasing. Official text is American English, so US spelling stands.

Tags in the table: **Term** (disagrees with §6 or with another Typhon string), **Grammar**, **Idiom**, **Style**, **Accuracy** (the English says something the data does not do), **Clarity**, **Consistency**. Rows marked *(optional)* are polish, not errors.

**Findings: 34 strings** (3 marked optional). By area: 7 effect texts, 6 agenda and attitude lines, 4 dialogue lines, 14 pedia entries, 3 War God Faith pedia entries.

## Checked and left alone

- **Official phrasing kept on purpose.** `LOC_DISTRICT_TSOD_MAGE_TOWER_DESCRIPTION` says 'Replaces the Campus district and cheaper to build', which is grammatically loose but copies the official Observatory and Acropolis text word for word; 'Enemy Spies operate at 1 level below normal in this city' and 'The Mage Tower district is defensible with a ranged attack' also copy official strings. The Burnstone description follows the official Expansion 2 Factory sentence exactly. `LOC_WORLD_CONGRESS_TSOD_DESANCTIFY_RELIGION_DESC` follows the official 'Strength (Combat and Religious)' pattern.
- **'grey' / 'greyish-white' / 'grey crystal'** stay. Official text uses both spellings (9 'grey', 3 'gray') and §6 fixes 'grey crystal'.
- **Typographic apostrophes.** 38 pedia strings use the curly apostrophe while the effect-text files use the straight one. Official pedia text also uses the curly one, so this is harmless. Straight double quotes appear beside curly apostrophes inside some pedia strings; leave unless the user wants one style everywhere.
- **Second person** appears only where it belongs: attitude lines, diplomacy lines, the loading-screen text and the leader's pedia overview. No effect text (traits, unit, district, building, project, resolution, notifications) uses it, and none opens with flavour. The 'A district / A building unique to Typhon' opener on the Mage Tower and Burnstone descriptions is the official unique-content sentence, not flavour.
- **Notifications and tooltips** (`WMD`, `Project`, `LeaderTrait`) read correctly. 'cast' in 'A Battle Mage army cast Annihilation Scar' is past tense and is clear next to 'can now cast' in the previous line.
- **War God Faith texts** (option name and description, religion name, pedia paragraph 1) are fine as written; the option name uses the §6 term 'War God Faith'.
- **City and citizen names.** All 57 city names match ids.md §7.1, and the citizen names match §6 and the file's own list. §7.1 is still marked as awaiting the user's review, so the names themselves were not re-judged.
- **Bare 'Cecil'** for the empire ('Cecil's bombardment', 'a mission to Cecil') is used consistently in the pedia and is left as is.
