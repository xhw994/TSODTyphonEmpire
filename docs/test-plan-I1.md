  `Players[0]:GetDiplomacy():DeclareWarOn(1); local u=UnitManager.InitUnit(1,'UNIT_MUSKETMAN',x,y); u:SetDamage(95)`
  （x、y 换成提丰单位旁边的格子）。打死它 → 火药亮尤里卡，Lua.log 有 `Kill boost`；再打死一个火枪手不触发；打死前置科技已研究的单位没有反应。
