## 检索里的其他发现

- 原著里找不到罗塞塔本人评价量产超凡者、战斗法师的话；以前以为在第693章，实际那一章他没出场，「根本之一」是安德莎说的。
- 原文中的「k / k们」是网站对「祂」的替换；台词里统一写「神明 / 它们」，避免游戏字体缺字。
- 第838章的章名就是「何不用之」（领袖能力击杀尤里卡的出处）；按用户规定，能力只叫「凡人的韧性」，这个名字不出现在游戏文本里。
