> 照塞西尔帝国的做法整理，上传步骤来自 `civ6-modding-publish` 技能。

> 文案文件：`README_EN.md`（工坊英文简介）、`README_CN.md`（工坊中文简介）、`README.md`（GitHub）。

## 1. 封面

### 1.1 塞西尔的封面是什么

| 项 | 内容 |
|---|---|
| 文件 | `TSODCecilEmpire/src/TSODCecilEmpire.jpg`，与部署目录里的 `Mods\TSODCecilEmpire\TSODCecilEmpire.jpg` 逐字节相同 |
| 规格 | **1024 × 1024**，JPEG（渐进式），598,730 字节（约 585 KB） |
| 登记 | 工程里是 `<Content Include="TSODCecilEmpire.jpg">`，生成的 `.modinfo` 里是 `<File>TSODCecilEmpire.jpg</File>`，所以它会随 mod 一起分发 |
| 历史 | 2024-05-26 加入（`e33ba72`），2024-05-31 改了封面上的错字（`df03e5d`） |
| 画面 | 深藏青底的官方插画：左边黑发的琥珀，右边扶额的高文，蓝披风。顶上一行白色细体、大字距的 `The sword of dawn`（插画自带）。下三分之一压一块黑色标题牌，金色细边，里面两行金字：`黎明之剑：塞西尔帝国`（楷体）和 `TSOD: Cecil Empire`（无衬线）。 |
| 源文件 | `imgs/Cover.jpg`（1080 × 1528 的原插画）、`imgs/TSOD Cecil Empire.psd`（50 MB，带图层的封面） |

梦境之城用同一版式：`TSODDreamCity/tools/make_cover.py` 用脚本出 1024 × 1024 的 JPEG（深色底、琥珀金的蜘蛛、标题牌）。脚本头注释写明，技能的发布清单只要求 512 × 512，这里为了和塞西尔那张一致才出 1024。标题牌的参数在脚本里：方框 `(52, 676, 972, 984)`，填充 `(9, 9, 11)`，3 px 描边，外发光加投影，顶部小字 Segoe UI Light 32 px、字距 0.5 em，中文楷体、英文 Candara。

### 1.2 提丰封面规格（建议）

| 项 | 建议 |
|---|---|
| 尺寸 | 1024 × 1024，正方形（技能要求至少 512 × 512；工坊页面上主预览只显示约 268 × 268，所以标题要大到缩小后还看得清） |
| 格式与体积 | JPEG，小于 1 MB（塞西尔 585 KB） |
| 版式 | 同塞西尔：上方 `The Sword of Dawn` 细体大字距，下三分之一黑色标题牌加金边，两行金字 |
| 文字 | 中文 `黎明之剑：提丰帝国`，英文 `TSOD: Typhon Empire` |
| 配色 | 提丰的国色是黑底红徽，备用红底金徽（`ids.md` §7.2）。牌子可以用同一套黑底金边；金色取国色里的金（228, 182, 78） |
| 画面 | 推荐 `images/罗塞塔·奥古斯都大帝.jpg`（1236 × 2000）：罗塞塔站在黑铁王座前的红色台阶上，红披风，两侧是四分盾加皇冠的红旗，正好是国徽的出处。取一块 1236 × 1236 的方形，从皇冠上方开始（约 y = 250），避开左上角自带的「黎明之剑」标志（顶上那行字由脚本另画）。备选是 `images/奥尔德南 冬日 修图.jpg`（2880 × 1440，已用作载入背景）居中裁方 |
| 做法 | 复制 `TSODDreamCity/tools/make_cover.py`，把蜘蛛换成背景图裁切，改标题与配色；输出到 `src/TSODTyphonEmpire.jpg` 或 `docs/` 都行（见下） |

### 1.3 封面放哪、怎么用

- 工坊预览图是**上传器里单独选的文件**，不要求在 mod 目录里。证据是上传器日志（`...\ModUploader\SteamUploader.log`）：梦境之城新建条目时写着 `Setting Preview Image to ...\TSODDreamCity\DreamCity.jpg`，图在仓库根目录而不在 `Mods\DreamCity` 里；塞西尔更新时写着 `Skipping preview image because none was specified`。
- 塞西尔把 jpg 登记成工程内容，随 mod 分发（多约 585 KB）。提丰可以照做（工程里加 `<Content Include="TSODTyphonEmpire.jpg">`，`.civ6proj` 归统筹者改），也可以不进 mod，只在上传时选。推荐不进 mod：订阅者的下载小一点。
- 现状：提丰仓库里还没有封面文件。
- 版权提示：塞西尔的封面用的是原作者发布的插画，提丰同理。用官方插画就要在简介的「素材来源」里写明（已写）。

## 3. 工坊标题与标签

### 标题

| 语言 | 建议 | 说明 |
|---|---|---|
| 英文（上传器里填） | `TSOD: Typhon Empire` | 塞西尔条目的网页标题就是 `TSOD: Cecil Empire`。`.modinfo` 里的英文名 `[The Sword of Dawn (TSOD)] Typhon Empire Civilization` 是游戏内「额外内容」里显示的名字，与工坊标题是两回事 |
| 中文（上传后在网页端补） | `黎明之剑：提丰帝国` | 与封面标题牌一致。上传器只认 ASCII，中文标题会乱码 |

标题要小于 128 个字符。

### 标签

塞西尔条目网页上显示的标签（匿名抓取）：`Mod`；`AI`、`Base Game`、`Rise and Fall`、`Gathering Storm`、`Buildings`、`Civilizations`、`Leaders`、`Units`。

提丰建议勾：

| 标签 | 理由 |
|---|---|
| Civilizations、Leaders | 内容本身 |
| Units、Buildings | 战斗法师、燃石酸化工厂 |
| AI | 有 AI 偏好（`TsoDTE_Agenda_AI.sql`） |
| Gathering Storm、Rise and Fall | 规则集与依赖 |

**不勾 Base Game**：提丰的数据只在 `RULESET_EXPANSION_2` 下加载，开局设置也只登记在风云变幻的玩家表里，原版规则下不可用。塞西尔勾了 Base Game，那是它页面上的写法，不要照搬。区域（法师塔）、宗教（战神教，若随版本发）有没有对应标签，要看上传器里的复选框列表，这里没法确认。

可见性：多数人选公开。想先自测可以先用「仅好友」，确认没问题再改公开。

## 4. 简介文本

- 英文简介：`README_EN.md`，7459 字符。工坊限制小于 8000，**只剩约 540 字符的余量**，加内容前先数字数。
- 中文简介：`README_CN.md`，约 2500 字符。
- 上传器只认 ASCII：`README_EN.md` 里有 `↑`、`远瞳` 三个非 ASCII 字符，直接粘进上传器会乱码。做法是上传器里先填一句纯 ASCII 的短简介，上传完到网页端再整段粘贴 BBCode。
- 工坊页面发布后，把条目链接填进 `README.md` 的 Workshop 链接、`README_*.md` 里想放的地方，以及 `.civ6proj` 的 `<Homepage>`（塞西尔的 `.modinfo` 里有 `Homepage`，指向自己的工坊条目；提丰的现在是空的）。填完要再传一个新版本。

## 5. 上传步骤

来自 `civ6-modding-publish`，按提丰的实际路径写。

### 5.1 上传前

1. 构建并部署到 `Mods\TSODTyphonEmpire\`（`.modinfo` 是构建时生成的，所以检查要对**部署出来的目录**跑）。
2. 在 `civ6-modding` 技能目录（`C:\Users\xegna\.claude\skills\civ6-modding\`）里跑四条检查，参数是部署目录：
   ```
   python scripts/validate_mod.py <部署目录>
   python scripts/loc_audit.py <部署目录>
   python scripts/modifier_lint.py <部署目录>
   python scripts/lua_lint.py <部署目录>
   ```
   `validate_mod.py` 查 GUID 格式、`<Files>` 登记的文件是否都存在、引用的文件是否都登记。上传器的硬性要求：`.modinfo` 存在；Mod ID 是合法 GUID；标题小于 128 字符；描述小于 8000 字符；不含可执行程序；不含压缩包；**不能声明了却不存在的文件**。
3. 人工确认：
   - 依赖声明齐了：风云变幻、迭起兴衰、埃塞俄比亚包（`.civ6proj` 的 `AssociationData` 已有这三项）。
   - 每个宣称支持的规则集都开局测过。提丰只支持风云变幻。
   - `AffectsSavedGames` 是 `true`（现状如此）。
   - `<Files>` 里没有 `.psd`、`.civ6proj`、`.git` 之类的开发文件。
   - **GUID `1e55d0b1-f5d9-48d4-a9b4-32e488b7bf21` 永远不改**；之后每次更新只加 `ModVersion`。
4. 测试记录里仍标着「待测」的项先清掉：见 `docs/test-log.md` 第四、五轮（神权理事会的目标列表、去神圣化的可见性、湮灭之创、黑暗时代各 2 个、法师塔与燃石酸化工厂的模型）。
5. 把 Steam 客户端语言**切成英文**。原版上传器不支持非 ASCII，中文标题和描述会乱码，还会把文字覆盖到当前语言版本的说明上。

### 5.2 上传

1. 启动上传器：`D:\Games\Steam\steamapps\common\Sid Meier's Civilization VI SDK\ModUploader\Firaxis.SteamWorkshop.exe`（也可以从 SDK 启动器里选「Steam 创意工坊上传器」）。
2. 新 mod：右上角 `Upload…`，三点浏览选 `Mods\TSODTyphonEmpire\TSODTyphonEmpire.modinfo`。
3. 填英文标题、短 ASCII 简介；**预览图选封面 jpg**；勾标签；选可见性；上传。
4. 如果卡在 `Committing Changes`：这是已知现象。去创意工坊页面看最后更新时间，是刚才就说明已经成功，直接关掉上传器。
5. 之后的更新：在列表里选中它，`Upload a New Version`。更新时不选预览图也可以（塞西尔的更新日志就是 `Skipping preview image`）。

### 5.3 上传后（网页端）

1. 到「您的文件 - 您发布的文件」里打开条目，改标题与描述：英文用 `README_EN.md`，再切到简体中文，填中文标题与 `README_CN.md`。
2. 传截图（第 2 节）。
3. 检查可见性，需要时设前置条目。埃塞俄比亚包是 DLC，工坊的前置条目只能选工坊物品，所以要在简介里写明（已写）。
4. 加入《黎明之剑》系列合集，与塞西尔、梦境之城放在一起（计划见 `docs/master-plan.md` §14）。
5. 记下条目 ID，回填 `<Homepage>` 与 README 里的链接，再传一个新版本。

### 5.4 不走创意工坊

`Mods\TSODTyphonEmpire\` 目录本身就是可分发的产物，打包成 zip 让别人解压到 `<用户目录>\Mods\`。Epic 版玩家没有创意工坊，只能这样。

## 6. 可选：繁体中文

塞西尔没有繁体中文，提丰不做。若以后要做：

- 文本用 `zh_Hant_HK` 语言键（游戏自带 `Vanilla_zh_Hant_HK.xml`），230 条 tag 与简体一一对应，另加工坊简介。
- 计划里的做法（`docs/impl-plan.md` WP20）是简体自动转换，再人工过一遍专有名词；提丰的专名（提丰、奥尔德南、冬堡、湮灭之创等）要统一，不能让转换器改坏。
- 这是可选项，不挡发布。

## 7. 没能确定的

- **塞西尔当年是不是用 mod 里的 jpg 当工坊预览图**：2024 年那次上传的日志已经被覆盖（日志只留了最近两次：梦境之城新建、塞西尔更新）。梦境之城的日志证明预览图可以是任意路径的文件，所以提丰不依赖 mod 内的 jpg。
- **塞西尔页面的标签、标题、图库数量**来自匿名抓取，页面还提示该条目「已被移出社区、仅作者可见」，结果可能不完整，当作参考。
- **工坊标签的完整列表**（有没有区域、宗教标签）只在上传器的复选框里，这里没法枚举。
- **图库图片的尺寸与数量上限**没有查到权威说法；建议 1920 × 1080 的 16:9。
- 提丰的**兼容测试**（和而不同、CIVITAS、Better City States、常用界面 mod、塞西尔和梦境之城同开）与**联机测试**在文档里是 WP20 和 WP21，没有记录显示已经做过。README 里因此没有写「测试过多少个 mod」，只写了联机尚未专门测试。
- 战神教在分支 `war-god-religion-1aa74f` 上，我读到的时候工作区正在合并（`git status` 里 `test-log.md`、`test-plan-I1.md`、`Art.xml`、`Overlay.artdef` 还是冲突状态），所以没有以它为准。三个 README 只留一行占位；它定稿后要回头改 README、标签（可能要加 Religion 标签）和截图。
