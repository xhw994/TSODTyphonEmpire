[b]本 MOD 添加了来自网络小说《黎明之剑》里的提丰帝国文明，以及它的皇帝罗塞塔·奥古斯都。[/b]

[hr][/hr]
[code]
[h1]文明：提丰帝国[/h1]
[h2]文明能力：超凡者的帝国[/h2]
拥有学院（含法师塔）的城市训练的陆地军事单位获得一次免费升级。学院和圣地区域每回合额外提供+1大将军点数。拥有军营的城市不受其他文明所创宗教的压力影响。
[h2]特色单位：战斗法师[/h2]
提丰的中世纪特色远程单位，替代弩手，且不会被替代。其战斗力随科技发展提升。与至少一个其他战斗法师相邻时，+5远程攻击力。组成军团或军队后每回合恢复生命；组成军队后可施放一次大规模杀伤性武器「湮灭之创」，施放后整支军队阵亡。
[h2]特色区域：法师塔[/h2]
提丰的特色科学区域，替代学院，造价更低，保留学院的全部相邻加成，并且每个相邻的军营区域额外+2科技。法师塔具有防御力且可执行远程攻击，敌方间谍在此城中的行动等级减1。
[h2]特色建筑：燃石酸化工厂[/h2]
提丰的特色建筑，替代工厂。+6生产力和+3科技值，延伸到6单元格内的所有市中心。本城所有农场+5食物，所有矿山和采石场+2生产力。
[/code]

[hr][/hr]
[code]
[h2]城市项目：去神圣化[/h2]
提丰专属。需要法师塔区域，研究大众传媒市政后解锁，可重复进行，造价随游戏进度增长。完成时将信仰值的一半转化为等量的科技值，并获得25点外交支持。
[h2]世界议会：神权理事会[/h2]
新增的世界议会决议，现代时代起出现，针对一个已创立的宗教。
去神圣化：所选宗教的所有单位-10战斗力（普通及宗教战斗力）。
世俗监督：所有文明都可以谴责所选宗教的单位，每次谴责获得25点外交支持。
只要启用本 MOD 就会进入决议池，不要求对局里有提丰。
[/code]

[hr][/hr]
[code]
[h1]领袖：罗塞塔·奥古斯都[/h1]
[h2]能力：凡人的韧性[/h2]
每进入一个新时代，从该时代随机获得1个尤里卡和1个鼓舞；若为黑暗时代，改为各2个。
战斗中击杀敌方单位后，若尚未研究该单位的前置科技，立即获得该科技的尤里卡（每项科技最多触发一次）。
[h2]议程：同类[/h2]
一直设法维持强大的陆军。喜欢陆军实力不弱于他的文明。讨厌把宗教传进他的城市的文明。
[h2]推荐游玩方式[/h2]
tldr：征服胜利为主，科技胜利为辅
提丰是学院和圣地都在为军队服务的文明。把法师塔和军营成对规划：相邻军营的法师塔能得到大量科技值，法师塔城市训练的陆地单位自带一次免费升级，学院和圣地区域还会源源不断地产出大将军点数。军营城市不怕外来宗教渗透，确保宗教信条的产出。战斗法师随科研进程自动变强，编成军队后可以用湮灭之创领先时代进行大规模杀伤性武器打击。燃石酸化工厂让农场和矿山一起丰产，同时提供生产力和科技值。罗塞塔本人擅长追赶：新时代和黑暗时代都有额外的尤里卡与鼓舞，主动和科技领先的对手交战也会带来尤里卡。到了后期，大众传媒之后的去神圣化可以把积攒的信仰值换成科技和外交支持，神权理事会则让你有机会削弱别人的宗教。
[/code]

[h1]MOD 兼容性[/h1]
需要《风云变幻》规则集、《迭起兴衰》，以及《埃塞俄比亚包》。
与[b]塞西尔帝国：[/b]同时启用后，罗塞塔与高文·塞西尔之间互有一条外交态度加成的联动。
本 MOD 替换了单位面板脚本，用来只显示湮灭之创，并且会与同样修改单位面板的 MOD（例如可莉 MOD）按社区约定接力载入。如果别的界面 MOD 把单位面板整个换掉，战斗法师的面板上可能会出现额外的原版核弹按钮。
如果有问题，请附上 MOD 列表以及 Database.log、Lua.log 文件反馈。

[h1]素材来源[/h1]
单位、区域和建筑的模型沿用游戏本体以及《埃塞俄比亚包》的官方素材。国徽、领袖立绘、背景和历史时刻插图来自小说作者远瞳的 B 站动态与《黎明之剑》官方设定图，部分图标由 AI（哈基米）生成后加工。如有侵权请联系删除。
